# PR の地図に、変わった関数とその説明を出す

PR の地図が、その PR で変わった関数（追加、コードの変更、移動、JSDoc だけの変更、削除）を見分けて札を付け、`apps/map/changes/` の変更メモに書いた説明を表示するようにする。
関数のページでは差分も開ける。

地図のこの機能は CLI（`packages/cli`）と地図（`apps/map`）の変更で、どちらも関数カタログの外にある。
動作を地図の上で確かめられるよう、同じ PR で UserInfo の 2 つの不具合も直した（`userinfo-token-fixes.md`）。
この PR の地図で札が付くのは、その修正で変わった関数である。

## 背景

これまでの PR の地図は main と同じ全体図を描くだけで、どの関数がどう変わったかを地図の上でたどれなかった。
説明はコードと同じリポジトリ（`apps/map/changes/`）に置き、PR と一緒にマージして残す。

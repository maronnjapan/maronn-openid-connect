# 早期リターンとエラーの分岐

エンドポイントの図は、ステップの並びだけでなく、実装中の条件と早期リターンを読む。
認可リクエストの解析で拒否された場合、prompt=none、SSO、機能がその場で応答した場合などに、後続のステップへ進む矢印を出さない。
機能のステップを外した構成では、そのブロック中の条件と return も外して図を作る。

if の成立・不成立、三項演算子、短絡評価を分岐として示し、return・throw の後の到達不能な処理を省く。
エラー応答は発生元ごとに別の箱へ分ける。
重なるエラーの矢印も別々の線で描き、条件ラベルを表示する。

## 背景

以前のエンドポイントの図はメタデータに書かれた主な分岐だけを使っていたため、実装の早期リターンが欠けていた。
また、すべてのエラーの矢印が同じ箱と縦線へ集まっていたため、どの処理が失敗した場合か追いにくかった。
